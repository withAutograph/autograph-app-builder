## Confirmed cross-layer gaps to close together

1. **Recover actual completed source transport provenance.** Earlier
   `prepare_workspace` copied source and returned new metadata while retaining
   the old workflow phase and workspace. `workspace_status` reports observed
   metadata, which is not the workflow's durable source baseline. Recover the
   genuine completed native tool result for the same owner/session/workspace,
   rather than trusting candidate metadata or replacing old plan provenance.
   Add a regression through the workflow adapter and actual history shape.

2. **Connect the development execution path to actual release capabilities.**
   The current private local launcher disables publication/bootstrap and does
   not forward the protected operator endpoint. The effect clients require an
   authenticated owner and protected HTTPS operator. The local adapter creates
   native sessions without forwarded user/workspace authority or canonical SQL
   session registration; project OIDC proves the machine, not the user. No
   effect-capable local profile was found. Either implement the genuine
   authenticated/durable local path, or use a qualified shared release for final
   hosted acceptance. The execution route must be selected before effect-capable implementation. Neither
   route may flip flags, invent claims, copy approvals or silently transplant the
   private local app. Editing a local factory does not update the remote operator.

3. **Finish central integration composition.** Approved service/provider/tool
   implementations and private custody exist on isolated branches, but their
   actual native endpoint, resources/schema worker adapters, captured source cut
   and fixed worker artifacts, source publication,
   owner/history readers, webhook receiver, ready/private/control-bootstrap ports
   and app-capability consumers must be assembled and tested together. Missing
   private profile/configuration remains explicit, never a fixture success.

4. **Provide reachable authenticated native delivery receipts.** A provider
   webhook cannot reach a loopback Mac endpoint. Identify the supported public
   callback and its actual runtime/configuration release. Preserve immutable
   accepted deployment IDs; no listing/SHA/time selection or manual promotion.
   Any shared operator release must be a concrete separately reviewable action.

5. **Complete optional-capability removal handoff.** Shared source uninstall and
   backend disable/drain already exist. The Builder release/revision contract
   does not yet freeze and execute their ordered handoff. Drain and independently verify stopped
   app work before removing source verification routes; preserve the peer app,
   shared connection, canonical data and history. The default release should
   explicitly retain the two exact previously owned optional environment rows
   read-only as a disabled tombstone, with no integration-readiness claim and
   with independently verified authority fencing. Exact environment deletion or
   credential/principal cleanup needs a separate concrete cleanup scope. Reuse
   the existing lifecycle; source omission alone is not a completed removal.

6. **Correct the consumed integration authoring guidance.** The Builder reference
   still names a generic host plus platform adapters instead of the existing
   configured shared Next host, and omits required `readObjects` and
   `checkedRelease` fields. Correct the shared reference and its generated
   bundle/parity through the supported task, rather than repairing generated
   app files on Builder's behalf.

7. **Close the central machine runtime environment.** The current central-only
   catalog still emits the platform Shell and the standard eager Gateway.
   Gateway startup needs additional platform identity/origin configuration that
   the central integration environment does not provide. Human Shell/Auth paths
   have further requirements. Implement an explicitly reviewed central-machine
   Services composition containing Gateway and Integrations, without Shell/Auth.
   Keep the existing neutral Gateway and MIT library as the final composition
   plane; allow only the exact signed readiness/control/provider-read lanes and
   deny browser/session/Auth/unrelated routes. Declare the mode in the approved
   source/manifest; never infer it from absent keys. Do not inherit customer Auth
   keys or add default Production fallbacks. Probe the actual compiled entrypoint
   with only declared central bindings and provider-owned native metadata.
