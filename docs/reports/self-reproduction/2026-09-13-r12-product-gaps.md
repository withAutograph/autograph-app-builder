## Feasible candidate-specific evaluator adapters

These are runnable adapter designs **once a preserved candidate runtime is available**, not executed results. The browser code hardcodes `/autograph-app-builder` (`app/components/BuilderClient.tsx:8`); establish the runtime's mount behavior before exercising routes.

| Check | Browser action | Independent readback and credit boundary |
| --- | --- | --- |
| Saved draft | Navigate to `/autograph-app-builder/workspace`, fill its single textarea, click `Save brief`, reload | GET `/autograph-app-builder/api/state` with the candidate's `x-autograph-tenant: local-workspace`; compare `draft.brief` and `savedAt`. Inspect app-cwd `.autograph-app-builder/local-workspace.json` (`app/lib/store.ts:6`) and restart the server for stronger durability proof. |
| Cancel state | Save draft, navigate to Review, click `Build local preview`, then `Cancel build` | GET state must show `build.status=canceled`, unchanged `runId`, and `recoveryAvailable=true`. Record state-transition coverage only; real-work cancellation remains absent. |
| Retry state | From canceled Review, click `Retry` | GET state must show a new `runId`, `status=building`, `phase=plan`. This does not prove failed-job retry. |
| Recovery state | Cancel, reload Review, click `Recover checkpoint` | GET state must retain `runId`, move to `phase=generate`, and preserve the saved brief. This is saved-state recovery, not resumption of an executing worker. |
| Documentation | Navigate to Docs; assert heading `How local creation works` | Static documentation is present at `app/components/BuilderClient.tsx:386`. Assess its accuracy separately from its accessibility. |
| False preview completion | Advance the build three times, open Preview, click `Open local preview` | Record the self-link and absence of an independently usable child workflow. Do not convert this into a preview pass. |
| False provider completion | Click `Emulate GitHub return` or `Emulate Vercel return` | Record state changes alongside the absence of authorization navigation and emulator callback evidence. Do not convert this into a provider-return pass. |

Missing selectors for authentication, provider authorization, account operations, or real child generation reflect missing product implementation here. Persistence selectors and the candidate state API are usable adapter opportunities. Keep those two categories separate in the evidence report, and never label a source inspection as a browser assertion or successful end-to-end workflow.
