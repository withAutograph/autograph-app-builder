Autograph keeps account connections and repository access in the browser, where you can see and approve them. You never need to paste a GitHub or Vercel token into a chat.

## Sign in to Autograph

When Codex asks you to connect, complete the browser sign-in using the same Autograph account and browser profile you use for the product. Return to the task once the browser confirms the connection.

## Give repository access

Autograph asks you to connect GitHub only when a workflow needs a repository. Choose the GitHub account or organization that owns the repository, then select the repository you want Autograph to use. If it is not listed, update the GitHub App's repository access and return to the same task.

## Connect services when needed

Some app workflows use services such as Vercel. Autograph presents the relevant connection when it is needed and tells you what it enables. Review the provider page before you approve it.

## You stay in control

Connecting an account lets Autograph prepare the requested work. It does not automatically publish an app or change a repository. Autograph asks again before it performs an action outside the product review flow.
