## Autograph is not available in a task

Confirm that the plugin is installed, then open a new Codex task. Existing tasks do not always reload newly installed tools. If it is still missing, repeat the steps in [Install Autograph](/docs/install-autograph).

## The browser asks you to sign in again

Return to the same Autograph origin in the browser and sign in with the account you used to start the task. Expired browser sessions and revoked access can require you to connect again.

## A repository is not listed

Use the GitHub connection page to update the GitHub App's access for the repository. When GitHub finishes, return to the task and try again. Selecting a repository name in chat cannot grant access by itself.

## A provider connection did not finish

Keep the task open, complete the provider's browser flow, and return to Autograph. If the connection still does not appear, reopen the connection step and make sure you are using the intended provider account.

## You want to change an app

Continue the existing app and describe the product change you want. You can refine its workflow before choosing any repository or publishing action.
