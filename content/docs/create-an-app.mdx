Open a fresh Codex task, mention **@Autograph App Builder**, and describe the result you want. A good first brief names the people using the app and the job they need to finish.

```text
Build an internal workspace where operations managers can review vendor onboarding requests, see the evidence for each request, and assign follow-up work to finance when tax information is incomplete.
```

## Start with the outcome

You do not need to choose a database, framework, or page layout. State the workflow, audience, and any requirements that matter to the experience. Autograph will suggest a practical starting point and explain the visible choices it makes.

## Review and refine

Explore the prototype in the browser. Ask for changes directly: add a step, rename a status, make a decision easier, or change what a person sees first. Use that review to settle the product before you ask Autograph to build it in a repository.

## Choose where it lives

When the product direction is ready, Autograph can ask you to select a GitHub repository. Confirm the repository in the browser, then review the proposed change before you choose to create it there.

## Keep going later

Your recent Autograph work is available from the same account. Ask to continue an app when you are ready to return to it.
